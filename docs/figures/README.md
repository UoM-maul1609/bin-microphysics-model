# Suggested BMM showcase figures

This directory is intended for publication-quality example figures linked from the project `README.md`.

Recommended figures:

1. `parcel_overview.png` — parcel temperature/RH/updraft together with liquid and ice water.
2. `size_distribution_evolution.png` — time- or temperature-evolving liquid and ice sectional distributions.
3. `ice_habit_evolution.png` — aspect ratio, density and monomer/aggregation state.
4. `inp_comparison.png` — primary-ice response for K-feldspar, Niemand desert dust, kaolinite, DeMott and Daily/DCMEX configurations.
5. `secondary_ice_example.png` — example showing primary ice followed by Hallett-Mossop or collisional multiplication.
6. `optical_response.png` — extinction/absorption or effective-diameter response.

For a clean GitHub landing page, use a consistent figure width/aspect ratio and avoid panels whose text is unreadable at roughly 900–1200 px page width. The existing scripts under `python/example_plot_bmm*.py` and `python/example_PSD_bmm*.py` are useful starting points, but dedicated README figures should ideally be saved directly into this directory with fixed labels and units.
